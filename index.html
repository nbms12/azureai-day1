Question 1
strong>Scenario: A startup launches a food delivery app. It needs to scale fast during launch week with no upfront hardware cost.
Answer: Public Cloud Pay-as-you-go and near-unlimited scale make public cloud ideal for a startup that needs to grow fast without buying hardware.
Question 2
Scenario: A national bank must store customer financial records under strict regulations that require data to remain on infrastructure it fully controls.
Answer: Private Cloud Full control over network, hardware, and security policy — plus data sovereignty and strict regulation — point to a private cloud.
Question 3
Scenario: A hospital keeps patient medical records in its own data center for compliance, but runs its public website and appointment booking on a cloud provider to handle traffic spikes.
Answer: Hybrid Cloud Sensitive data stays private while elastic workloads run on public cloud — connected by VPN or dedicated links.
Question 4
Scenario: A global gaming company needs to serve millions of players across multiple regions with automatic scaling and pays only for what it uses each month.
Answer: Public Cloud Global regions, near-unlimited scale, and pay-as-you-go billing are the core strengths of public cloud providers like AWS, Azure, and GCP.
Question 5
Scenario: A government defense agency runs legacy systems that must remain on-premises and requires full control over every hardware and network component.
Answer: Private Cloud Legacy systems, strict regulation, and the need for full hardware/network control make a private (or on-premises) deployment the right choice.
Question 6
Scenario: A retail company is migrating to the cloud step by step — keeping its core ERP system on-premises for now while moving its e-commerce storefront to a public cloud.
Answer: Hybrid Cloud Mixing on-premises infrastructure with public cloud — and migrating gradually — is the defining trait of a hybrid model.
